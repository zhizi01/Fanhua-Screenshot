# 繁花有图

Windows 桌面截图与图片标注工具，当前版本 **1.1.0**。启动后驻留系统托盘，通过 `Alt + A` 截图；截取后直接打开图片预览，需要标注时再展开编辑工具。设置窗口仅提供快捷操作和常用设置。

## 日常使用

1. 启动程序后，在系统托盘中找到“繁花有图”。
2. 按 `Alt + A`，在当前桌面的冻结画面上选择：移动鼠标自动识别窗口，单击截取该窗口；按住左键拖动可自由框选。
3. 截图完成后，在预览窗口中选择固定、复制、编辑、识别文字、添加水印或保存。
4. 关闭预览窗口会丢弃尚未保存的图片和编辑内容。关闭设置窗口只收起到托盘，程序仍在后台运行。

双击托盘图标可打开设置；右键托盘可开始截图、打开图片、进入设置或退出程序。若 `Alt + A` 被其他应用占用，解除冲突后可在托盘菜单中重试注册，也可直接点击“开始截图”。

截图遮罩在后台预加载并重复使用，背景准备完成后才显示，减少反复建窗和画面闪动。快捷键截图保留当前桌面上的窗口；从设置或预览窗口点击截图时，只暂时隐藏这个来源窗口，结束或取消后恢复。

## 图片编辑

| 工具 | 操作 |
| --- | --- |
| 文字 | 点击图片添加批注，可输入多行文字，再次选中后修改字体、字号、颜色或删除。 |
| 序号 | 支持 `1, 2, 3`、`A, B, C`、`壹, 贰, 叁`，可修改序号、添加说明。序号头大小与说明文字字号独立设置。 |
| 箭头 | 按住左键拖动绘制，选中后可移动整体或分别拖动两端，调整颜色、线宽和箭头头大小。 |
| 马赛克 | 拖动框选打码区域，调整像素块强度；每个区域独立保留。 |
| 选择 | 点击图片中的标注或右侧图层，重新编辑、拖动或删除。 |
| 撤销／重做 | 恢复标注内容、样式、位置、删除操作及当前图片的水印设置。 |

桌面版枚举系统和当前用户安装的字体，包含可用的中文名称与其他本地化名称，不截断字体列表。可搜索字体，并在安装新字体后点击刷新。字体不可用或缺少相应字形时按系统字体回退。字母序号在 `Z` 后继续为 `AA`；中文大写序号支持至 `玖仟玖佰玖拾玖`。

马赛克不会修改内存中的原图，删除区域后可恢复原始像素。固定按钮使当前预览窗口保持置顶。按住 `Ctrl` 滚动鼠标滚轮可围绕鼠标所在位置缩放画面，也可使用底部的缩放、100% 和适应窗口按钮；缩放只改变查看比例。

## 识别文字

点击“识别文字”即可识别当前整张图片，包括已添加的标注和水印。结果按行显示，可直接修改并一键复制；没有识别到文字时会明确提示，可切换识别语言后重试。

识别在本机离线完成。优先使用系统可用的 Windows OCR 语言；安装包同时包含 Tesseract 引擎及简体中文、英文模型，在相应原生能力不可用或调用失败时提供中英文识别。无需额外下载模型，不上传图片。识别效果受文字清晰度、字号和排版影响。

“翻译”按钮与接口已预留，当前禁用，尚未实现实际翻译。

## 水印

在预览窗口打开“水印”，启用后更改会实时应用到图片：

- 文字水印：多行文字、系统字体、字号和颜色。
- 图片水印：选择 PNG 或 JPEG；透明 PNG 保留透明部分，可调整大小。
- 铺设：左上、上中、右上、左中、居中、右中、左下、下中、右下，或全图平铺；支持透明度、旋转、边距和平铺间距。
- 存档：为文字或图片水印命名后另存，之后可加载、更新或删除。删除存档不会删除当前图片中的水印；“移除水印”只移除当前图片上的水印。

水印存档保存在本机应用用户数据目录，重启后仍可使用。最多保存 30 个，存档库总大小不超过 64 MB。图片水印源文件不超过 16 MB、1600 万像素；导入时最长边等比例缩至 2048 像素，转换后的 PNG 不超过 8 MB。

## 保存与复制

点击保存或按 `Ctrl + S`，先选择格式，再通过系统对话框选择位置。

| 格式 | 特点 |
| --- | --- |
| PNG | 无损，保留透明背景，适合文字和界面截图。 |
| JPEG | 可调整质量；透明区域填充为白色。 |
| WebP | 可调整质量，支持透明背景。 |
| BMP | 未压缩位图；透明区域填充为白色，文件通常较大。 |

复制和保存均合并原图、标注及水印，保持原始图像像素尺寸。JPEG、WebP 的质量范围为 10%～100%。选择格式后请保留对应文件后缀；若手动改成不匹配的后缀，程序会提示重新保存。

可编辑图层只保存在当前预览窗口的内存中，导出的图片不包含图层项目数据。保存后仍可在当前窗口继续编辑，重新打开已导出的文件时则作为普通图片处理。程序不自动保存截图，也不上传图片。

## 快捷键

| 场景 | 快捷键 | 动作 |
| --- | --- | --- |
| 全局 | `Alt + A` | 开始截图 |
| 截图 | `Esc` 或鼠标右键 | 取消截图 |
| 截图 | `Enter` | 确认当前选区；未选择区域时截取整屏 |
| 预览／编辑 | `Ctrl + S` | 选择格式并保存图片 |
| 预览／编辑 | `Ctrl + C` | 复制图片 |
| 预览／编辑 | `Ctrl` + 鼠标滚轮 | 以鼠标位置为中心缩放画面 |
| 编辑 | `V` / `T` / `N` / `A` / `M` | 选择／文字／序号／箭头／马赛克 |
| 编辑 | `Ctrl + Z` | 撤销 |
| 编辑 | `Ctrl + Y` 或 `Ctrl + Shift + Z` | 重做 |
| 编辑 | `Delete` 或 `Backspace` | 删除选中标注 |
| 编辑 | 方向键 | 移动选中标注 1 像素 |
| 编辑 | `Shift` + 方向键 | 移动选中标注 10 像素 |

文字输入框、字体选择框及滑块获得焦点时，按键用于当前控件，不会触发画布编辑快捷键。保存、OCR、水印弹窗打开时，画布快捷键暂停。

## 从源码运行

需要 Windows、Node.js 22.12 或更高版本、npm。推荐 Node.js 24。窗口识别使用系统自带的 Windows PowerShell，无需安装原生编译工具链。

```powershell
npm ci
npm run dev
```

开发命令启动 Vite 和 Electron，并打开设置窗口。第一次运行 Electron 时可能需要下载其二进制文件。

运行本地构建：

```powershell
npm run build
npm start
```

`npm start` 默认只驻留系统托盘。需要直接打开设置窗口时使用：

```powershell
npm start -- --show-window
```

浏览器界面演示：

```powershell
npm run dev:web
```

打开终端显示的本机地址。浏览器模式使用演示图片，可验证编辑、缩放、多格式下载和水印；水印存档写入该浏览器的本地存储。真实桌面截图、全局快捷键、托盘、系统字体枚举、OCR、窗口固定和开机启动由 Electron 提供。

## 构建 Windows 程序

```powershell
npm run pack
npm run dist
```

- `npm run pack`：生成 `release/win-unpacked/繁花有图.exe`，需保留同目录的运行文件。
- `npm run dist`：生成 `release/Fanhua-Screenshot-1.1.0-Setup.exe` 安装包。
- 安装包支持选择安装目录、创建桌面快捷方式。开机启动设置在安装后的 Windows 应用中使用。
- 当前未配置代码签名证书，构建产物未签名。

内置 OCR 语言文件位于 `resources/ocr/`，构建时会复制进应用资源目录。请保留该目录及随附的来源和许可证说明，避免打包后缺失离线识别能力。

## 验证

```powershell
npm run typecheck
npm test
npm run test:e2e
```

单元测试覆盖坐标换算、窗口边界、序号和箭头、编辑历史、马赛克、水印布局与存档、格式编码、OCR 处理和原生异常恢复。端到端测试使用 Windows 上的 Microsoft Edge，并启动真实 Electron 验证桌面与编辑流程；具体已通过项目和实测边界见 [验证记录](docs/VALIDATION.md)。

可分别运行：

```powershell
npx playwright test --project=browser
npx playwright test --project=electron
npm run test:packaged
```

`test:packaged` 需先完成 `pack` 或 `dist`，使用打包后的 EXE 重跑原生流程，以检查构建资源和桌面功能。测试定义与当轮实测结果分开记录，不以源码测试代替安装包验证。

测试图片写入 `artifacts/`，失败诊断写入 `test-results/`，两者均不纳入 Git。真实桌面测试期间会打开测试窗口并短暂覆盖屏幕，请避免同时操作鼠标。

## 当前范围

- Windows 为主要目标平台；原生窗口识别和系统字体读取使用 Windows API。
- 多显示器分别创建截图遮罩。一次框选位于一块显示器内，暂不支持一次拖动跨屏截图；跨屏窗口只截取当前屏幕内可见部分。
- 窗口识别服务不可用时可继续手动框选。屏幕布局变化或截图窗口异常时会取消当前截图并恢复原窗口。
- macOS、Linux 未完成实际验证，且没有对应的原生窗口识别实现。
- OCR 已实现本机识别；翻译目前只有预留入口，不提供翻译结果。
- 图层项目文件、自动保存和截图历史目前不在实现范围内。
