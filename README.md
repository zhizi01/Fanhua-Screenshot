# 繁花有图

Windows 桌面截图与图片标注工具。启动后驻留系统托盘，通过 `Alt + A` 截图；截取后直接打开图片预览。设置窗口仅提供快捷操作和常用设置。

## 日常使用

1. 启动程序后，在系统托盘中找到“繁花有图”。
2. 按 `Alt + A`：移动鼠标自动识别窗口，单击截取该窗口；按住左键拖动可自由框选。
3. 截图完成后，在预览窗口中选择固定、复制、编辑或保存。
4. 关闭预览窗口会丢弃尚未保存的图片和编辑内容。关闭设置窗口只收起到托盘，程序仍在后台运行。

双击托盘图标可打开设置；右键托盘可开始截图、打开图片、进入设置或退出程序。若 `Alt + A` 被其他应用占用，解除冲突后可在托盘菜单中重试注册，也可直接点击“开始截图”。

## 图片编辑

| 工具 | 操作 |
| --- | --- |
| 文字 | 点击图片添加批注，可输入多行文字，修改字体、字号和颜色。 |
| 序号 | 支持 `1, 2, 3`、`A, B, C`、`壹, 贰, 叁`，可修改序号数值、添加步骤说明及调整文字样式。 |
| 马赛克 | 拖动框选打码区域，调整像素块强度；每个区域独立保留。 |
| 选择 | 点击图片中的标注或右侧图层，重新编辑、拖动或删除。 |
| 撤销／重做 | 恢复标注内容、样式、位置及删除操作。 |

字体列表读取本机已安装字体，也可输入字体名称。字体不可用时按系统字体回退。字母序号在 `Z` 后继续为 `AA`；中文大写序号支持至 `玖仟玖佰玖拾玖`。

马赛克不会修改内存中的原图，删除区域后可恢复原始像素。固定按钮使当前预览窗口保持置顶；复制和保存均包含当前标注，并保持原始图像像素尺寸。

**保存格式为 PNG。** 导出的 PNG 会合并原图和标注；可编辑图层仅保存在当前预览窗口的内存中。保存后仍可在当前窗口继续编辑，重新打开 PNG 时则作为普通图片处理。程序不自动保存图片，也不上传图片。

## 快捷键

| 场景 | 快捷键 | 动作 |
| --- | --- | --- |
| 全局 | `Alt + A` | 开始截图 |
| 截图 | `Esc` 或鼠标右键 | 取消截图 |
| 截图 | `Enter` | 确认当前选区；未选择区域时截取整屏 |
| 预览／编辑 | `Ctrl + S` | 保存 PNG |
| 预览／编辑 | `Ctrl + C` | 复制图片 |
| 编辑 | `V` / `T` / `N` / `M` | 选择／文字／序号／马赛克 |
| 编辑 | `Ctrl + Z` | 撤销 |
| 编辑 | `Ctrl + Y` 或 `Ctrl + Shift + Z` | 重做 |
| 编辑 | `Delete` 或 `Backspace` | 删除选中标注 |
| 编辑 | 方向键 | 移动选中标注 1 像素 |
| 编辑 | `Shift` + 方向键 | 移动选中标注 10 像素 |

文字输入框、字体选择框及滑块获得焦点时，按键用于当前控件，不会触发画布编辑快捷键。

## 从源码运行

需要 Windows、Node.js 22.12 或更高版本、npm。推荐 Node.js 24。窗口识别使用系统自带的 Windows PowerShell，无需安装原生编译工具链。

```powershell
npm ci
npm run dev
```

开发命令启动 Vite 和 Electron，并打开设置窗口。第一次运行 Electron 时可能需要下载其二进制文件。

运行本地构建：

```powershell
npm run build
npm start
```

`npm start` 默认只驻留系统托盘。需要直接打开设置窗口时使用：

```powershell
npm start -- --show-window
```

浏览器界面演示：

```powershell
npm run dev:web
```

打开终端显示的本机地址。浏览器模式使用演示图片，便于查看界面和验证编辑交互；真实桌面截图、全局快捷键、托盘、窗口固定和开机启动由 Electron 提供。

## 构建 Windows 程序

```powershell
npm run pack
npm run dist
```

- `npm run pack`：生成 `release/win-unpacked/繁花有图.exe`，需保留同目录的运行文件。
- `npm run dist`：生成 `release/Fanhua-Screenshot-1.0.0-Setup.exe` 安装包。
- 安装包支持选择安装目录、创建桌面快捷方式。开机启动设置在安装后的 Windows 应用中使用。
- 当前未配置代码签名证书，构建产物未签名。

## 验证

```powershell
npm run typecheck
npm test
npm run test:e2e
```

单元测试覆盖坐标换算、窗口边界、序号格式、编辑历史、马赛克渲染、原生服务异常和截图窗口恢复。端到端测试使用 Windows 上的 Microsoft Edge，并启动真实 Electron 验证截图、预览、编辑和导出。

可分别运行：

```powershell
npx playwright test --project=browser
npx playwright test --project=electron
npm run test:packaged
```

`test:packaged` 需先完成 `pack` 或 `dist`，使用打包后的 EXE 重跑原生流程，覆盖后台启动、原生字体服务和截图。

测试图片写入 `artifacts/`，失败诊断写入 `test-results/`，两者均不纳入 Git。真实桌面测试期间会打开测试窗口并短暂覆盖屏幕，请避免同时操作鼠标。

## 当前范围

- Windows 为主要目标平台；原生窗口识别和系统字体读取使用 Windows API。
- 多显示器分别创建截图遮罩。一次框选位于一块显示器内，暂不支持一次拖动跨屏截图；跨屏窗口只截取当前屏幕内可见部分。
- 窗口识别服务不可用时可继续手动框选。屏幕布局变化或截图窗口异常时会取消当前截图并恢复原窗口。
- macOS、Linux 未完成实际验证，且没有对应的原生窗口识别实现。
- 图层项目文件、自动保存和截图历史目前不在实现范围内。
