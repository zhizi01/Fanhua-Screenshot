# 繁花有图

Windows x64 桌面截图、图片标注与 PDF 分页编辑工具，当前版本 **1.6.0**。启动后驻留系统托盘，通过 `Alt + A` 截图；截取后直接打开图片预览，需要标注时再展开编辑工具。设置窗口仅提供快捷操作和常用设置。

## 日常使用

1. 启动程序后，在系统托盘中找到“繁花有图”。
2. 按 `Alt + A`，在当前桌面的冻结画面上选择：移动鼠标自动识别窗口，单击截取该窗口；按住左键拖动可自由框选。
3. 截图完成后，在预览窗口中选择固定、复制、共享、编辑、识别文字、添加水印或保存。共享按钮展开菜单，再选择“通过LocalSend共享”。
4. 关闭预览窗口会丢弃尚未保存的图片和编辑内容。关闭设置窗口只收起到托盘，程序仍在后台运行。

双击托盘图标可打开设置；右键托盘可开始截图、打开图片、进入设置或退出程序。若 `Alt + A` 被其他应用占用，解除冲突后可在托盘菜单中重试注册，也可直接点击“开始截图”。

截图遮罩在后台预加载并重复使用，背景准备完成后才显示，减少反复建窗和画面闪动。快捷键截图保留当前桌面上的窗口；从设置或预览窗口点击截图时，只暂时隐藏这个来源窗口，结束或取消后恢复。

## 图片编辑

安装后，在资源管理器中右键 PNG、JPEG、静态 WebP、未压缩 BMP 或 PDF 文件，选择“使用繁花有图编辑”，会直接打开编辑窗口；已有后台实例时在该实例中新开文件。Windows 11 通常需先选择“显示更多选项”。菜单项跟随安装时选择的当前用户／所有用户范围，不改变默认打开软件；卸载时清理本安装对应的菜单项。运行源码或免安装目录不会自动注册菜单。

预览图片内部也有右键菜单，可进入编辑、复制、保存；编辑时可对右键命中的标注修改、删除，或撤销、重做。右键空白位置不会删除此前选中的标注；`Esc` 收起菜单并将焦点还给画布。原图文件只有通过保存对话框确认覆盖时才会改变。

| 工具 | 操作 |
| --- | --- |
| 文字 | 点击图片添加批注，可输入多行文字，再次选中后修改字体、字号、颜色或删除。 |
| 序号 | 支持 `1, 2, 3`、`A, B, C`、`壹, 贰, 叁`，可修改序号、添加说明。序号头大小与说明文字字号独立设置。 |
| 箭头 | 按住左键拖动绘制，选中后可移动整体或分别拖动两端，调整颜色、线宽和箭头头大小。 |
| 方框／圆形 | 拖动绘制空心矩形或椭圆；按住 `Shift` 绘制正方形或正圆。支持实线、虚线、点线，边框粗细和颜色；选中后拖动边框移动，拖动八个控制点调整大小。 |
| 马赛克 | 拖动框选打码区域，调整像素块强度；每个区域独立保留。 |
| 选择 | 点击图片中的标注或右侧图层，重新编辑、拖动或删除。 |
| 撤销／重做 | 恢复标注内容、样式、位置、删除操作及当前图片的水印设置。 |

桌面版枚举系统和当前用户安装的字体，包含可用的中文名称与其他本地化名称，不截断字体列表。可搜索字体，并在安装新字体后点击刷新。字体不可用或缺少相应字形时按系统字体回退。字母序号在 `Z` 后继续为 `AA`；中文大写序号支持至 `玖仟玖佰玖拾玖`。

马赛克不会修改内存中的原图，删除区域后可恢复原始像素。固定按钮使当前预览窗口保持置顶。按住 `Ctrl` 滚动鼠标滚轮可围绕鼠标所在位置缩放画面，也可使用底部的缩放、100% 和适应窗口按钮；缩放只改变查看比例。

## PDF 文件

从设置窗口或托盘的“打开图片 / PDF”选择 PDF，也可安装后使用资源管理器右键直接编辑。文件在本机解析，无需联网、Adobe Acrobat 或额外阅读器。

- 使用图片上方的上一页、下一页或页码输入框切页。每页分别保留标注、马赛克、水印、撤销记录和保存状态，翻页不会丢失编辑。
- 当前页可继续使用文字、序号、箭头、形状、打码、OCR、中英翻译、复制及 LocalSend 共享。复制和共享输出当前页编辑后的图片。
- 翻页后清除上一页 OCR/译文；识别面板保持打开时自动识别新页。若旧任务尚未完成，只等待并识别最新停留的页面，不显示旧页结果。OCR 始终读取当前页原始画面，不含后加标注。
- 保存选择 PNG、JPEG、WebP、BMP 时，输出当前页图片；选择 PDF 时，可保存当前页或按原顺序保存全部页面，包含每页各自的编辑与水印。普通截图或图片也能保存为单页 PDF。
- PDF 导出保留原页面尺寸与朝向，**页面会合成为静态图片，不保留原 PDF 的可选文字、链接或交互表单**。OCR 虚线框和翻译遮罩不进入输出。
- 导出显示页数进度，页面合成阶段可以取消；最后写入阶段会等待保存完成。取消或写入失败不会预先破坏已有目标文件。编辑本身不改写源文件，关闭窗口不自动保存。

PDF 默认按 144 DPI 渲染；超大页面会等比降低分辨率，使单页不超过 1600 万像素或 8192 像素单边。预览缩放不改变导出分辨率。普通图片转 PDF 按 96 DPI 换算纸张尺寸。

当前支持最多 200 页、96 MB 的 PDF；暂不支持需要密码的 PDF，请先解密。PDF 输出每页不超过 1600 万像素，页面图片合计不超过 128 MB，页面物理尺寸每边不超过 14400 点；超过限制会明确提示，不输出残缺文件。实现、依赖来源与验证方式见 [PDF 支持说明](docs/PDF.md)。

## 识别文字与段落

点击“识别文字”会在图片右侧展开独立段落栏，并识别打开时的整张原图，不包含本次新增的文字、序号、箭头、形状、水印或马赛克。识别期间仍可查看、缩放和编辑图片。桌面窗口会按所需宽度展开，编辑属性栏和文字识别栏可以同时使用。

识别结果按段落列出，图片对应位置显示虚线框和轻微遮罩：

- 点击图片中的识别区域，右侧自动滚动至对应段落并选中。
- 点击右侧段落，可定位图片中的对应区域，并直接修正文字；支持复制单段或全部文字。
- 识别框、遮罩和段落编号都是临时查看标记，**不会保存或复制到图片中**，修改识别文字也不会改变原图。
- 关闭识别栏会隐藏位置标记，但在当前预览窗口保留结果和修正文字；再次打开可继续查看。
- 图片标注或水印变化不影响原图识别结果，无需重复识别。主动重新识别仍读取原图，并替换段落结果，包括此前手动修正的文字。

这里的原图是本次截图或打开的图片：本次打码覆盖的原图文字仍可被识别；若重新打开已保存的图片，其中已经合成的标注属于该图片像素，无法自动分离。

系统仅返回文字行时，程序根据行距、位置和字号推断段落；复杂排版的分段和阅读顺序可能需要人工核对。没有识别到文字时会明确提示，可切换语言后重试。

识别在本机离线完成。优先使用系统可用的 Windows OCR 语言；安装包同时包含 Tesseract 引擎及简体中文、英文模型，在相应原生能力不可用或调用失败时提供中英文识别。无需额外下载模型，不上传图片。识别效果受文字清晰度、字号和排版影响。

## 中英离线翻译

点击预览工具栏“翻译”，展开 OCR 段落栏；尚未识别时先识别原图。选择“英文 → 简体中文”或“中文 → 英文”，点击“全部翻译”，也可点击段落旁的翻译按钮只处理该段。译文逐段显示在右侧原文下方，同时在图片对应识别框内用浅色遮罩覆盖原文并显示译文。可复制单段或全部已有译文；原文仍可编辑和复制。

原位译文随图片缩放、滚动，点击后仍定位右侧段落；按区域大小自动调整字号，小框或过长译文会截断显示，悬停或右侧列表可查看全文。关闭翻译恢复原有识别框，关闭识别栏隐藏全部虚拟标记。

- 修改原文会清除该段旧译文；翻译期间修改原文、切换方向或重新 OCR 会停止在途任务，避免混用结果。
- 可随时取消，已完成的译文保留。关闭识别栏停止在途任务并保留当前图片已完成的结果；关闭图片窗口后释放相关任务。
- 译文与 OCR 位置框都是查看信息，不会写入保存或复制的图片。
- 中英两个方向的 OPUS-MT Q8 模型随完整安装包附带，使用 CPU，无需 API Key、Python、Ollama 或联网。运行时禁止远程模型下载，不上传图片或文字。
- 模型只在翻译时加载；使用独立后台进程并限制推理线程数，同时只保留一个方向，空闲一分钟后释放。多个预览窗口共享一个翻译任务，正在忙时其他请求会提示稍后重试。

长段落按句子和模型实际 token 数拆分，不静默截断；一次最多 200 段、总计 60000 字符，单段最多 12000 字符。翻译效果受 OCR 错字、专业术语和上下文影响，可先修正原文再翻译。当前只支持中英互译。

选型背景见 [本地翻译方案调查](docs/LOCAL_TRANSLATION.md)；模型固定版本、来源与许可见 [翻译模型说明](resources/translation/README.md)。

## 水印

在预览窗口打开“水印”，启用后更改会实时应用到图片：

- 文字水印：多行文字、系统字体、字号和颜色。
- 图片水印：选择 PNG 或 JPEG；透明 PNG 保留透明部分，可调整大小。
- 铺设：左上、上中、右上、左中、居中、右中、左下、下中、右下，或全图平铺；支持透明度、旋转、边距和平铺间距。
- 存档：为文字或图片水印命名后另存，之后可加载、更新或删除。删除存档不会删除当前图片中的水印；“移除水印”只移除当前图片上的水印。

水印存档保存在本机应用用户数据目录，重启后仍可使用。最多保存 30 个，存档库总大小不超过 64 MB。图片水印源文件不超过 16 MB、1600 万像素；导入时最长边等比例缩至 2048 像素，转换后的 PNG 不超过 8 MB。

## 保存与复制

点击保存或按 `Ctrl + S`，先选择格式，再通过系统对话框选择位置。

| 格式 | 特点 |
| --- | --- |
| PNG | 无损，保留透明背景，适合文字和界面截图。 |
| JPEG | 可调整质量；透明区域填充为白色。 |
| WebP | 可调整质量，支持透明背景。 |
| BMP | 未压缩位图；透明区域填充为白色，文件通常较大。 |
| PDF | 将图片或所选 PDF 页面、标注和水印合成静态文档；不保留可选文字及交互。 |

复制和保存均合并原图、标注及水印，保持原始图像像素尺寸。JPEG、WebP 的质量范围为 10%～100%。选择格式后请保留对应文件后缀；若手动改成不匹配的后缀，程序会提示重新保存。

复制按钮旁的下拉菜单提供两种方式：

- **复制到剪贴板**：无损 PNG。直接点击“复制”或按 `Ctrl + C` 始终使用此模式。
- **复制到 DeskFlow 剪贴板**：将编辑好的图片按 JPG、质量 60% 编码，透明部分填白，保留原尺寸。鼠标悬停显示“由于DeskFlow传输有限制，会造成质量压缩。”。真实 JPEG 字节与系统图片兼容表示同时写入剪贴板，由已运行的 DeskFlow 负责同步。

DeskFlow 没有独立于系统的专用剪贴板；其 Windows 版本可能将图片转换为未压缩位图，因此 JPG 文件变小不保证实际同步数据量变小，也不保证绕过其大小限制。本工具不自动缩小分辨率或更改 DeskFlow 配置。实现和验证见 [DeskFlow 剪贴板说明](docs/DESKFLOW.md)。

可编辑图层只保存在当前预览窗口的内存中，导出的图片不包含图层项目数据。保存后仍可在当前窗口继续编辑，重新打开已导出的文件时则作为普通图片处理。程序不自动保存截图；OCR 和翻译不上传图片。

## 通过 LocalSend 共享

点击预览工具栏的“共享”展开方式菜单，再选择“通过LocalSend共享”。仅展开菜单不会启动程序或生成临时图片。选定后将当前原图、全部编辑标注和水印合成为 PNG，交给本机 LocalSend 并唤起其发送界面。**在 LocalSend 中选择接收设备后才会发送**；本工具不会自动选择设备，也不会将“已打开 LocalSend”当成“传输成功”。OCR 位置框和译文不进入共享图片。

支持自动查找已运行的 LocalSend、注册表安装记录和常见安装位置；未找到时可选择已安装或便携版的 `localsend_app.exe`，之后记住该位置。取消选择会返回预览。LocalSend 需单独安装，接收端也需准备好相应软件。

共享 PNG 临时放在本机 `fanhua-localsend` 专用临时目录，关闭预览或退出本工具不会立即删除，以免影响 LocalSend 稍后的读取。下次启动或共享时清理超过 7 天的本工具临时共享文件，启动失败时清理该次文件。常规关闭未保存图片不产生这些共享文件。

调用依据与本机验证见 [LocalSend 集成说明](docs/LOCALSEND.md)。

## 从源码运行

仅支持 Windows x64，需 x64 Node.js 22.13 或更高版本、npm。推荐 Node.js 24。窗口识别使用系统自带的 Windows PowerShell，无需安装原生编译工具链。

```powershell
npm ci
npm run models:prepare
npm run dev
```

开发命令启动 Vite 和 Electron，并打开设置窗口。第一次运行 Electron 时可能需要下载其二进制文件。`models:prepare` 从官方来源下载固定版本的中英模型并校验 SHA-256；仅首次准备需要联网。未准备模型时仍可使用截图和 OCR，翻译会提示模型缺失。

`dev`、`dev:web` 和 `build` 会从已安装的 PDF.js 依赖自动准备本地 worker、字体、CMap 与解码资源，无运行时下载。只有打开 PDF 时才加载解析库。

运行本地构建：

```powershell
npm run build
npm start
```

`npm start` 默认只驻留系统托盘。需要直接打开设置窗口时使用：

```powershell
npm start -- --show-window
```

浏览器界面演示：

```powershell
npm run dev:web
```

打开终端显示的本机地址。浏览器模式使用演示图片，可验证编辑、缩放、多格式下载和水印；水印存档写入该浏览器的本地存储。真实桌面截图、全局快捷键、托盘、系统字体枚举、OCR、窗口固定和开机启动由 Electron 提供。

## 构建 Windows 程序

```powershell
npm run pack
npm run dist
```

- `npm run pack`：生成 `release/1.6.0/win-unpacked/繁花有图.exe`，需保留同目录的运行文件。
- `npm run dist`：生成 `release/1.6.0/Fanhua-Screenshot-1.6.0-Setup.exe` 安装包。产物按版本分目录，避免覆盖正在运行的旧版本。
- 安装包支持选择安装目录、创建桌面快捷方式、注册图片右键编辑。开机启动设置在安装后的 Windows 应用中使用。
- 开发、启动和构建命令检查 Windows x64 环境；打包显式固定 `--win --x64`，并通过 `beforePack` 拒绝 macOS、Linux、ARM64 等其他目标。浏览器演示只用于界面开发，不是额外平台发行版。
- 当前未配置代码签名证书，构建产物未签名。

内置 OCR 语言文件位于 `resources/ocr/`，构建时会复制进应用资源目录。请保留该目录及随附的来源和许可证说明，避免打包后缺失离线识别能力。

翻译模型位于 `resources/translation/`，大模型下载文件不纳入 Git。打包前自动执行 `models:check`，仅核对已有文件的大小与 SHA-256，缺失或损坏时阻止生成不完整安装包；请先运行 `npm run models:prepare`。安装包保留模型署名和许可证文件。

PDF 服务回归验证分页生成、输入限制、取消与原子写入；渲染回归使用真实 Electron `file://`，验证离线中文、旋转/裁剪/大页、损坏及密码文件、取消和关闭；界面回归覆盖逐页编辑、OCR 翻页队列、图片和 PDF 导出、回开后的页面像素。打包后运行 `node scripts/verify-pdf-ui.cjs "release/1.6.0/win-unpacked/繁花有图.exe"`。

npm run test:translation:service

服务验证覆盖输入限制、长文切分、取消和资源回收；离线推理验证封禁子进程网络调用后执行真实中英模型；界面验证启动真实 Electron，覆盖 OCR、双向翻译、原文修改失效、文字复制、图片导出隔离与取消恢复。需先准备模型，打包版验证还需先生成对应版本程序。

测试图片写入 `artifacts/`，失败诊断写入 `test-results/`，两者均不纳入 Git。真实桌面测试期间会打开测试窗口并短暂覆盖屏幕，请避免同时操作鼠标。

## 当前范围

- 仅支持 Windows x64；原生窗口识别和系统字体读取使用 Windows API。
- 多显示器分别创建截图遮罩。一次框选位于一块显示器内，暂不支持一次拖动跨屏截图；跨屏窗口只截取当前屏幕内可见部分。
- 窗口识别服务不可用时可继续手动框选。屏幕布局变化或截图窗口异常时会取消当前截图并恢复原窗口。
- 不提供 macOS、Linux 或 Windows ARM64 构建。
- OCR 和中英翻译均在本机运行，模型随完整安装包提供；其他翻译语言不在当前范围。
- 图层项目文件、自动保存和截图历史目前不在实现范围内。

进程职责、截图坐标约定和编辑模型见 [架构说明](docs/ARCHITECTURE.md)。
